# 실제 컴파일 진단 기반 재보정

## 변경

실제 C# 정상 기준 실행을 `dotnet build`와 검사 프로그램 실행으로 분리했다. 빌드가 실패하면 프로그램을 실행하지 않으며 호스트가 `compilationFailure`에 phase·종료 코드와 제한된 오류 코드·등록 파일·행/열·메시지를 기록한다. 같은 phase의 합계 120초 예산은 유지한다. 프로그램이 출력한 가짜 `error CS1061`은 빌드 실패로 취급하지 않는다.

보정 모델에는 현재 컴파일 진단과 현재 검사 원문을 전달한다. 읽기 전용·작은 검사 patch 하나·승인 전 범위/현재성 검사·승인 후 같은 기준과 후보 재실행을 유지한다. 이미 통과하여 보호된 검사를 변경하지 않고, 기존 최대 시도와 동일 실패 signature 제한도 유지한다. 별도 DB migration이나 IPC API는 추가하지 않았다.

실제 C# 회귀에서 `Generation` 단정 실패 → 첫 patch의 `Timeout.InfiniteTimeSpan` CS1061 → 실제 컴파일 진단을 받은 두 번째 patch → 기준/후보 재통과를 확인했다. 이 기능 회귀의 모델은 stub이다. 다른 답안이 공유 작업공간을 사용한 뒤에는 원문을 승인된 쓰기로 복원하고, 오래된 gate 대신 새 컴파일 실행 증거를 요구하는 경로도 검증했다.

## 비교 조건과 예산

학습 3사례, 평가 2문제 × 각 조건 2회, `gpt-5.6-sol / medium`, 초기 요청·코드·시간 예산·도구 금지와 원래 구현 60점 + 검사 40점 배점을 유지했다. 컴파일·추출 함수 원문도 기존과 동일함을 고정 전 확인했다.

최초 생성 8회, 총 호출 최대 16회, 조건별 보정 최대 4회를 유지했다. 모든 최초 생성·1차 보정을 먼저 진행한 뒤, 첫 승인 patch가 검사 파일의 실제 컴파일 오류를 만들었을 때만 남은 해당 조건 예산으로 추가 보정 1회를 허용했다. 양쪽 규칙은 같다. 기준 소스·숨겨진 검사·비공개 변형·점수는 모델에 제공하지 않았고 평가 결과를 Learn에 넣지 않았다.

이번 모델 호출 소스는 **7562b56**으로 고정했다. 실제 호출은 최초 8회 + 1차 보정 4회 = **12회**였다. 1차 보정 뒤 재보정 대상 컴파일 오류가 발생하지 않아 실제 모델의 2차 호출은 **0회**다. 이 결과만으로 Timeout의 실제 모델 2차 복구 성공률을 주장하지 않는다.

## 후보 시간 초과와 채점 누락

학습 전 LeasePool 첫 후보는 DisposeAsync의 완료 TaskCompletionSource를 보관하지 않고, 마지막 완료 경로가 예외를 던져 반환 task를 완료하지 못하는 구현이었다. 실제 후보 실행이 60초 idle 제한에 걸리자 평가 driver가 이 답안의 채점을 건너뛰었다. 따라서 최초 `repair-summary.json`은 7개 답안만 채점되어 학습 전 평균이 null이었다.

이 driver 결함은 RED `44fddc6`, GREEN **439999b**에서 수정했다. 유효한 동결 제출 쌍은 실행 검증 오류와 관계없이 같은 채점기로 평가하고, 원문과 검증 오류를 보존한다. 이 수정은 모델 호출이 끝난 뒤 적용했으며 모델을 다시 실행하지 않았다.

이번 결과는 원래 실행 기록을 변경하지 않고 별도 보완 채점으로 완성했다. SQLite의 승인 입력과 정상 기준 통과·보호된 검사 원문이 제출 파일과 같음을 먼저 확인했다. 빠진 한 답안만 **동일한 기존 채점 함수·45초 제한·60+40 산식**으로 한 번 채점했다. 숨겨진 구현 검사 프로그램은 시간 초과로 그룹 결과를 반환하지 않아 기존 산식상 구현 0점, 정상 기준과 변형 검사에서 회귀 40점을 받았다. 기존 7개 점수를 다시 계산하거나 유리한 재실행 결과로 교체하지 않았다.

`repair-attempts.json`·`repair-summary.json`은 원래 기록 그대로다. 완성된 표는 `completed-grading-view.json`·`completed-grading-summary.json`이며, `supplemental-grading.json`에 원본 SHA256·승인 입력 대조·보완 실행 결과를 남겼다. 후보의 실제 검증 실패/불확실 상태를 성공으로 변경하거나 완료 처리하지 않았다.
